# 🔒 Security Policy

## Supported Versions

We currently provide security updates only for the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

---

## Reporting a Vulnerability

If you discover a security issue, please **do not open a public issue**.  
Instead, report it privately by emailing us at **[saky.aiu22@gmail.com]**.  

We will:  
- Acknowledge your report within **48 hours**  
- Provide regular status updates  
- Work with you on a fix and release timeline  

Thank you for helping keep this project safe and secure.
