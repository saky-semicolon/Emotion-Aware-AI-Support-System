## 📄Emotion-Aware AI Support System – Documentation

This folder contains the full documentation, visuals, UI/GIFs, and source files for the **Emotion-Aware AI Complaint Management System**, a smart university-level platform that uses voice-based emotion recognition to prioritize student complaints.

---

### 📂 Structure

Documentation Page/
├── app/ # Flask app with feedback model
├── templates/ # Jinja HTML templates (index.html)
├── static/ # JS, CSS files
├── medias/ # Diagrams, GIFs, and images
├── run.py # Entry point
├── requirements.txt # Dependencies
└── README.md # This file


### 🚀 Features

- 📄 Interactive Documentation Page (Flask-based)
- 🧠 Emotion-Based Complaint Architecture Diagrams
- 📊 Project Visuals (GIFs, charts, system flows)
- 💬 Feedback Form with Database Integration
- 🌐 Ready for multi-language support
- 📥 PDF report, Readme, License, and PlantUML diagrams


### 🛠️ Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/documentation-repo
   cd "Documentation Page"
   ```

2. Set up a virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
    flask run --port 5000

### 🌐 Access Locally

Visit: [http://localhost:5000](http://localhost:5000)
